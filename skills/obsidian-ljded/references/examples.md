## 示例 1：编程笔记（普通知识点）

### 改写前

```markdown
Python 装饰器
装饰器本质上是一个函数，它接收一个函数作为参数并返回一个新函数。
常见内置装饰器有 @staticmethod 和 @classmethod。
GIL 全局解释器锁让 Python 同一时刻只能执行一个线程，它是 1991 年引入的。
```

### 改写后

```markdown
#闪卡/编程/Python

# Python 装饰器

装饰器::接收一个函数作为参数并返回一个新函数的函数。

常见内置装饰器：

@staticmethod 和 @classmethod 的区别
?
- `@staticmethod`：不接收隐式第一参数，与类无绑定
- `@classmethod`：接收 `cls` 作为第一参数，可访问类属性

==as;;GIL（全局解释器锁）== 让 CPython^[原笔记误写为 Python，GIL 是 CPython 实现细节] 同一时刻只能执行一个线程。^[原笔记"它是 1991 年引入的"表述无可靠依据，已删除]
```

要点说明：
- 短定义 → 单行闪卡 `::`
- 对比类内容 → 多行闪卡 `?`
- 段落关键术语 → 完型填空
- 发现错误 → 直接修复 + `^[原文]` 行级脚注说明改动

## 示例 2：文学笔记（人物条目）

### 改写前

```markdown
司马迁，字子长，西汉人，世称"史圣"。
```

### 改写后

```markdown
#闪卡/语文/文学常识

司马迁::字子长，西汉人。
司马迁的世称::"史圣"。
```

要点说明：
- 人物条目含多个属性 → 拆为多张 `::` 卡，一张卡只问一个属性；不要把字、朝代、称号全部挤进一个答案
- 拆分原则见 SKILL.md 铁律"一个知识点一张卡"

## 示例 3：诗歌笔记

### 改写前

```markdown
静夜思 李白
床前明月光，疑是地上霜。
举头望明月，低头思故乡。

水调歌头·明月几时有 苏轼
明月几时有？把酒问青天。不知天上宫阙，今夕是何年。
```

### 改写后

```markdown
#闪卡/语文/古诗

==as;;床前明月光^[一作"看山月"] ==，==sa;;疑是地上霜==。
==as;;举头望明月==，==sa;;低头思故乡==。
-==aa;;《静夜思》==

==as;;明月几时有==？==sa;;把酒问青天==。
==as;;不知天上宫阙==，==sa;;今夕是何年==。
-==aa;;《水调歌头·明月几时有》==
```

要点说明：
- 同一句群内状态码 `as`/`sa` **交替**：第 1 张卡提问 `as` 挖空（前半句）、显示 `sa` 挖空（后半句），第 2 张卡反之——两张卡分别问前半句和后半句，实现双向互问；**不要全部用 `as`**（否则第 2 张卡全部显示，失去考查意义）
- 出处行对应用 `aa`（2 个 a，与该组闪卡数一致）
- 异文用 `^[注释]` 标注，且 `]` 与 `==` 之间留一个空格
- 出处行格式：`-==aa;;《出处》==`

## 示例 4：序号模式的分组挖空

### 改写后片段

```markdown
#闪卡/历史

==1;;秦始皇== 于 ==1;;公元前 221 年== 统一六国。
==2;;汉武帝== 时期推行 ==2;;罢黜百家，独尊儒术==。
丝绸之路开通于 ==西汉== 时期。
```

- 序号 1 组（秦始皇相关 2 处同卡）、序号 2 组（汉武帝相关 2 处同卡）、无序号挖空 1 处 → 共 **3 张卡**。

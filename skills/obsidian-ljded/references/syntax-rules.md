# Spaced Repetition 闪卡语法细则

本文档是生成闪卡时的**权威语法依据**。生成任何闪卡前务必逐条对照。

## 0. 文档标签

- 文档顶部插入 `#闪卡`，支持多级分类：`#闪卡/编程/Python`。
- Spaced Repetition 插件依靠该标签识别哪些笔记参与复习，缺失则闪卡不会被调度。

## 1. 单行闪卡

```
问题::答案        ← 单向（只看问题想答案）
问题:::答案       ← 双向（问题→答案、答案→问题各生成一张卡）
```

- `::` 与 `:::` 前后建议各留一个空格，提升可读性。
- 适合短问答：术语定义、缩写全称、命令用途等。

## 2. 多行闪卡

```
问题第一行
问题第二行（可选）
?
答案内容
```

- `?`（单向）或 `??`（双向）**必须独占一行**，上方为问题、下方为答案。
- 适合答案包含多行、列表、代码块的内容。

## 3. 完型填空（重点，规则最易错）

基础形式：`这是一段包含 ==挖空内容== 的文字。`

带标记形式：`==[序号或状态码;;]挖空内容[;;提示]==`

结构拆解（方括号部分可选）：
- `==` …… `==`：高亮挖空区域
- 前缀 `标记;;`：序号（数字）或状态码（a/s/h 组合）
- 内容：被挖空的文字
- 后缀 `;;提示`：显示在挖空处的提示文字

### 3.1 默认模式（无标记）

- 每个 `==挖空==` 各自独立生成 1 张闪卡。
- **闪卡数量 = 挖空数量**。

### 3.2 序号模式

```
==1;;中国的首都是北京==
==1;;北京是政治中心==
==2;;上海是经济中心==
这是一句 ==无序号挖空== 的话。
```

- 相同序号的挖空属于**同一张卡**（复习时同时挖空、同时显示）。
- 每个无序号挖空各自独立成卡。
- **闪卡数量 = 不同序号的个数 + 无序号挖空的个数**。
- 上例：序号 1 一组、序号 2 一组、无序号 1 处 → 共 **3 张卡**。

### 3.3 状态码模式

状态码含义：
- `a` = 提问（ask）：该张卡中此挖空作为问题被遮住
- `s` = 显示（show）：该张卡中此挖空直接显示
- `h` = 隐藏（hide）：该张卡中此挖空整段隐藏（不显示也不提问）

规则：
1. **同一组内每个挖空的状态码个数必须完全一致**（如全部 2 个码 `as`，或全部 4 个码 `aash`）。
2. **状态码个数 = 该组生成的闪卡数**。第 i 张卡按每个挖空的第 i 个状态码渲染。
3. 示例：

```
==as;;李白== 是 ==sa;;唐代== 诗人。
```

- 两个挖空均为 2 个状态码 → 生成 **2 张卡**：
  - 第 1 张："李白"取 a（提问）、"唐代"取 s（显示）→ 问作者
  - 第 2 张："李白"取 s（显示）、"唐代"取 a（提问）→ 问朝代
- 这实现了"双向提问"效果：两个事实互为题干与答案。

4. 混用 `h` 的示例：

```
==ahs;;关键概念== 出现在 ==sha;;某章节==。
```

- 各 3 个码 → 3 张卡：第 1 张问概念（章节隐藏），第 2 张整句隐藏概念、问章节，第 3 张全部显示作回顾。

### 3.4 提示文字

```
==1;;光合作用;;植物的什么过程==
```

复习时挖空处显示提示"植物的什么过程"。提示为可选项。

### 3.5 常见错误（务必避免）

- ❌ 同组挖空状态码个数不一致（`==as;;甲==` 与 `==a;;乙==` 混用）
- ❌ 状态码用了 a/s/h 以外的字符
- ❌ 前缀忘记写 `;;` 分隔符（`==as内容==` 是错的）
- ❌ 挖空内容内部出现未转义的 `==`，导致高亮提前闭合
- ❌ 需要互问的一组挖空全部使用 `as`（这样第 1 张卡全问、第 2 张卡全显示，失去考查意义）——同一句群应 `as`/`sa` 交替，让每张卡各有提问点
- ❌ 脚注 `^[...]` 紧贴闭合 `==`（`^[注释]==`）——必须在 `]` 与 `==` 之间留一个空格：`^[注释] ==`
- ❌ **同一句内多个无序号挖空互漏**——两个及以上独立 `==挖空==` 在同一句且语义上属同一组知识时，生成多张卡，未遮的挖空直接剧透答案
- ❌ 人物卡名字/字号/朝代/称号拆成多个独立挖空——复习时看到未遮的属性就能猜到被遮的那个
- ❌ 两个 `==` 相邻不隔开——`=="A"=="B"==` 解析正常但肉眼难辨，用 `==1;;A==、==1;;B==` 清晰分组

### 3.6 多空防漏铁律

**同一句内 2+ 个独立 `==挖空==`，如果它们语义属于同一组知识点，必须用同序号 `==1;;` 分组。** 否则生成多张卡，每张卡未遮的挖空直接曝光被遮的答案。

典型犯规场景与修复：

| 犯规（漏题） | 修复（同序号组，1 卡同考） |
|-------------|--------------------------|
| `"三班"指==班彪==、==班昭==、==班固==。` → 3卡互漏 | `==1;;班彪==、==1;;班昭==、==1;;班固==` |
| `"辞赋之祖"指==荀子==与==屈原==。` → 2卡互漏 | `==1;;荀子==与==1;;屈原==` |
| `兵家代表人物是==孙武==和==孙膑==。` → 2卡互漏 | `==1;;孙武==和==1;;孙膑==` |
| `陶渊明"金刚怒目"的代表作有==《读山海经》==和==《咏荆轲》==。` → 2卡互漏 | `==1;;《读山海经》==和==1;;《咏荆轲》==` |
| `孔子，名==丘==，字==仲尼==，...鲁国==人` → 3卡互漏 | `==1;;丘==，字==1;;仲尼==，...==1;;鲁国==人` |

**判断标准**：遮掉一个挖空后，句中其它未遮内容是否足以推导出答案？是 → 必须同序号分组；否 → 可独立成卡。

**唯一例外**：`as`/`sa` 交替的诗句挖空（状态码模式）本身就是故意设计为双向互问，不适用此规则。

## 4. 闪卡内容支持（富媒体与表格限制）

**原则：笔记里能渲染的内容，闪卡里都能显示。** 闪卡的问题与答案不限于纯文字，可包含：

- 图片（嵌入 `![[图片.png]]`）
- 数学公式（`$...$` / `$$...$$`）
- 代码块、列表、引用块、Callout 等

**表格的限制与例外：**

- **整张表不能作为闪卡内容**（如把表格放进 `?` 多行闪卡的答案区）：Markdown 表格前必须有一个空行才能渲染，而**空行会被 Spaced Repetition 插件视为闪卡结束**——表格会脱离闪卡、解析错乱。
- **但表格内可以做挖空**：在单元格中写 `==挖空==`（可带序号或 `==as;;...==` 状态码），**整张表格会作为一个闪卡单位**——复习时显示整张表作为上下文，其中的挖空按完型填空规则成卡提问（默认每个挖空一张卡、同序号同卡、`as`/`sa` 交替互问）。挖空卡锚定在表格块上、以表为单位，因此不受"表格前需空行"的限制。
- 若确需把整张表作为一张卡的内容，必须在插件设置里单独配置"闪卡结束标志"。但该设置默认未开启，且**一旦开启，所有没有结束标志的已有闪卡会全部错乱**——此设置需谨慎对待，默认不开启。
- 因此默认做法：**表格只做挖空，不整表入卡**；需要整体记忆的表格内容改写为列表（`- 项目：值`）后再做成闪卡。

## 5. `::` 与完型填空的选择规则

`::` 把题干和答案割裂为两个独立面；`==完型==` 把答案嵌入完整句子，复习时多一层"句子结构"的联想锚点。**能用完型的场景优先用完型**。

### 5.1 用 `==完型==` 的场景

| 卡类型 | 示例 |
|--------|------|
| **定义/性质**（答案是句中关键词） | `《春秋》是第一部==编年体==史书。` |
| **别名/称号**（答案是标签词） | `《淮南子》又名==《淮南鸿烈》==。` / `李白被称为=="诗仙"==。` |
| **特点/风格**（短答案嵌入句） | `《战国策》的艺术风格为=="辩丽横肆"==。` |
| **作者归属**（"X 的作者是"自然成句） | `《文心雕龙》的作者是==刘勰==。` |
| **人物基本属性**（字/号/世称） | `曹植，字==子建==，世称==陈思王==。` |
| **地位/第一/最早** | `《尔雅》是我国第一部==词典==。` |

### 5.2 保留 `::` 或改用 `?` 的场景

| 卡类型 | 示例 | 原因 |
|--------|------|------|
| **列表/枚举**（3~6 项） | `四书指==1;;《论语》==、==1;;《孟子》==、==1;;《大学》==、==1;;《中庸》==。` | 同序号组一张卡考全部，可加 `;;提示` |
| **列表过长**（≥7 项） | `唐宋八大家::...` | 拆组或改用 `?` 多行卡 |
| **人物评价**（谁对谁的评价） | `苏轼对王维的评价::"诗中有画，画中有诗"。` | 问题本身是关系查询 |
| **并称/合称** | `"王孟韦柳"指::...` | 可考虑完型但通常多项 |
| **指代/出处**（问某词指什么） | `《谏逐客书》中的"书"指的是::上书、奏章。` | 已优化问法，如需改完型保持同一句式 |
| **长答案**（超过一行） | `《文心雕龙》的历史地位::...` | 太长的答案嵌入句子破坏可读性 |
| **多事实复合** | `屈原的地位::...` | 应拆卡或改用 `?` 多行卡 |

### 5.3 列表类：完型的序号组用法

列表类（3~6 项）推荐用同序号组完型 + 可选提示：

```
四书指==1;;《论语》;;孔门弟子编纂==、==1;;《孟子》;;亚圣孟轲==、==1;;《大学》;;曾子==、==1;;《中庸》;;子思==。
```

- 全部同一序号 `1` → **只生成 1 张卡**，4 个空同时考
- `;;提示` 可选，给记忆支架
- 比 `::` 优势：复习时看到完整句式 `四书指___、___、___、___` + 提示，而不是裸列表

原则：**≤6 项用同序号完型，≥7 项拆组或改用 `?` 多行卡**。

### 5.4 `::` 转完型时的文字打磨

转换不是机械替换，必须保证语句自然流畅：

**删冗余谓语**
- ❌ `《战国策》的思想倾向是突出表现==纵横家==思想。` → "是突出表现"冗余
- ✅ `《战国策》突出表现==纵横家==思想。`

**删"地位是/特点是"赘词**
- ❌ `《战国策》在叙事散文中的地位是==叙事散文的巅峰==。` → 主语+地位重复
- ✅ `《战国策》被称为==叙事散文的巅峰==。`

**拆分多事实复合句**
- ❌ `屈原是中国第一位伟大的==爱国诗人==，==浪漫主义==文学的奠基人。` → 2个独立空互漏
- ✅ 拆为两句或分组：`屈原是中国第一位伟大的==1;;爱国诗人==，==1;;浪漫主义==文学的奠基人。`

**并称/合称要分组**
- ❌ `"潘江陆海"指==潘岳==与==陆机==。` → 2卡互漏
- ✅ `"潘江陆海"指==1;;潘岳==与==1;;陆机==。` → 1卡同考

**判断口诀**：改完后遮住挖空，读一遍句子——如果像正常中文就通过；如果读起来拗口或缺信息，就需要打磨。

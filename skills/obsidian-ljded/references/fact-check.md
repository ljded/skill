# 笔记事实核查指南

修改笔记中"疑似错误"的事实性内容前，必须先核实。**核实不了就不改，只标注 `^[存疑：...]`**。

## 1. 何时需要核查

| 情形 | 处理方式 |
|------|---------|
| 明确错别字（"按装"→"安装"）、明显笔误 | 直接修，加 `^[原文]` 脚注，不用查 |
| 年代、作者、字号、书名/出处归属 | **必须查** |
| 诗句原文与版本异文（如"床前明月光"一作"看山月"） | **必须查** |
| 公式形式、定理表述、常数数值 | **必须查** |
| 用户笔记与常识冲突但拿不准 | **必须查**；查无实据则保留原文 + `^[存疑：...]` |

## 2. 搜索方式

优先使用内置搜索/网页抓取工具；需要多引擎交叉验证时，按查询语言选引擎（URL 中 `{关键词}` 需替换并做 URL 编码）：

### 中文内容（古诗词、文史常识）——国内引擎

- 百度：`https://www.baidu.com/s?wd={关键词}`
- Bing 国内版：`https://cn.bing.com/search?q={关键词}&ensearch=0`
- 搜狗微信（公众号文章，适合查证解读类内容）：`https://wx.sogou.com/weixin?type=2&query={关键词}`
- 360：`https://www.so.com/s?q={关键词}`

### 英文内容——国际引擎

- Google：`https://www.google.com/search?q={关键词}`
- DuckDuckGo：`https://duckduckgo.com/html/?q={关键词}`
- Brave：`https://search.brave.com/search?q={关键词}`

### 运算符速查

| 写法 | 作用 | 示例 |
|------|------|------|
| `"..."` | 精确匹配 | `"疑是地上霜"` |
| `site:` | 站内搜索 | `site:gushiwen.cn 静夜思` |
| `-` | 排除 | `静夜思 -广告` |
| `filetype:` | 指定文件类型 | `高等数学公式 filetype:pdf` |
| `&tbs=qdr:y` | Google 时间过滤（近一年；h/d/w/m 同理） | 查时效性内容 |

## 3. 核查纪律

- **双源一致才认定**：至少两个独立来源结论一致才可认定为事实；单一来源视为存疑。
- **控制频率**：批量核查时请求间隔 1-2 秒；遇 403/429 停手重试一次，仍失败则换引擎。
- **结论留痕**：核实后修改的，脚注写明依据，如 `^[原笔记误作"李白"，实为杜甫，据《全唐诗》]`。
- **查无实据**：保留原文，加 `^[存疑：原笔记作 xxx，未查到可靠来源]`，不擅自改动。
